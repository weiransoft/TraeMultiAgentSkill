# 没有文档、看不懂代码，怎么接手一个黑盒系统？

遗留系统最劝退的样子：没有文档、没有源码，只有一个登录页和一句"你自己摸"。
问老员工，回复是"点这个按钮会改数据，别乱点"——摸都不敢摸，还谈什么理解？

multi-agent-team v2.9 的 SU（系统理解）能力，把"摸底"变成
**全程只读、零副作用的自动化反向理解**：

- **Playwright 自动登录**（支持人工已登录态旁路），**图式 BFS 遍历**全部页面，
  动作按危险度三级分级——高危按钮**零点击只记录**，网络层直接拦截一切非 GET 请求
- **MySQL / PostgreSQL 只读内省**：表、列注释、主外键、索引、采样逐值脱敏，
  会话级只读 + SQL 语句白名单双护栏；**Redis** SCAN 游标采集 + 只读命令白名单
- **UI ↔ API ↔ DB 三角关联**：页面、表、接口、键模式之间的关联必须有
  重合度/包含度数值证据，不靠"看着像"
- **证据与结论严格分离**：脚本层零 LLM 调用、不出语义结论；
  语义结论由宿主 LLM 按契约回填，CLI 校验收口——LLM 不许冒充证据

五条安全红线不可协商：凭据不落盘明文、DB 只读白名单、Redis 只读白名单、
浏览器只 GET、危险按钮零点击。依赖缺失时显式声明"未采集"并给出安装命令——
**诚实降级，绝不拿假数据冒充。**

产出固定 10 节《系统功能理解文档》+ 机读 JSON + Mermaid 图，
断点续跑、SIGINT 后可 `--resume`。先看懂，再动手。
