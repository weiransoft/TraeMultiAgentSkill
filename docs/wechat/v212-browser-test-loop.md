# Agent 说"我测过了，都正常"——证据呢？

让 AI 打开浏览器点两下，回来告诉你"功能正常"，你敢信吗？
没有记录的测试，和没测没有区别。

v2.12 把浏览器测试做成**全程留痕的闭环**：

- **先规划再动手**：一次可感知动作登记为 OP 操作点（带代码位置和可断言预期）；
  数据按六类设计——正例 / 边界 / 非法 / 异常 / 时序；用例分 P0-P2，
  主路径必须 P0。测试四件套先过四角色评审才许执行
- **三宿主逐一执行**：agent-browser、Trae 内置浏览器、Chrome DevTools MCP，
  每个宿主都走一遍同一套用例
- **每一步结构化落盘**：`recorder step` 记操作、`assert` 记断言
  （必须有预期值和**实际值**）、`shot` 记截图（文件必须真实存在）——
  schema 强制，想含糊都含糊不了
- **收尾门禁**：`finalize` 核对 P0 通过率，不到 100% 不放行
- **阻碍六类协议**：选择器失效、数据准备、环境故障……先解决再推进，不许绕

测试报告从"写作文"变成"查台账"。summary.json / summary.md 双格式产出，
每一条绿灯背后都有步骤、断言和截图撑着。
