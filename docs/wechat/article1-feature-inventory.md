# 用例全过，为什么 bug 还是漏到了线上？

因为没人回答过一个朴素的问题：**这个页面到底有几个功能？**

"测试覆盖率 100%"从来不代表"功能覆盖 100%"——覆盖率统计的是代码行，
而你根本没为那个"确认删除"按钮写过用例，它就永远不会红给你看。

multi-agent-team v2.14 的解法很直接：测试规划阶段先产出一份
**FUNC-\* 每页功能清单**——逐页列全每一个功能项，分五种类型：

- **interactive**（按钮/开关/拖拽）：必须 P0 用例覆盖，**禁止豁免**
- **form**（表单提交）：必须 P0 覆盖，**禁止豁免**
- **display / nav**（展示/跳转）：必须覆盖，或写下书面豁免理由
- **branch**（条件分支）：必须覆盖对应分支条件

每一项都要给出 `文件:行号` 的代码证据——清单不是拍脑袋列的，
是从源码里逐项核对出来的。豁免可以，但 `waive_reason` 必须写清楚，
空着就是 schema 校验不通过。

这份清单就是后面覆盖门禁的**分母**。先知道有什么，再谈测没测到。
