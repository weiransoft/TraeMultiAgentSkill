# "覆盖率我口头报 100%"——这句话在 finalize 面前一文不值

很多测试报告的覆盖率是**自报**的：执行的人说测了，就算测了。
v2.14 的 feature_gate 不接受任何自报。

收尾时 `finalize` 会从落盘的执行记录里**现算**一张
**FUNC × PASS 断言关联矩阵**：

- 功能项算"被覆盖"的唯一标准：至少关联 **1 条 PASS 断言**
- fail 断言不算覆盖——你碰过它不行，你得**测过它、它还是绿的**
- interactive / form 任一功能项没覆盖 → 整体 **gate=FAIL**，一票拦下
- summary.md 直接渲染**缺口清单**：哪个页面、哪种类型、缺哪个功能项，逐条可追

还防了一手更阴的：执行到一半偷偷改功能清单原件、把难测的项删掉——
"移动球门"。v2.14 在 `run` 时就把清单原件的 **SHA256** 写进 run 元数据，
finalize 重新核对，哈希对不上直接 FAIL。

覆盖不是声明出来的，是脚本从证据里算出来的。
