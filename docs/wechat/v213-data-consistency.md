# 接口 200、页面弹"成功"——数据真落对库了吗？

UI 自动化有个盲区：它只看界面。接口返回 200、页面弹出"保存成功"，
它就绿灯放行——至于用户名大小写被 transform 吃掉、明细表少写了一行、
订单状态跳了非法迁移，界面全看不见。

v2.13 往下扎一层，把**数据一致性**纳入门禁：

- **DC-* 数据契约**：表单字段 → API → DB 列 → 回读展示 的全链路映射，
  每个字段带 transform 声明和 `文件:行号` 证据——没有证据，不许默认"应该一致"
- **before/after 快照对照**：动作执行前后各拉一次 DB 快照，
  `dc-check` 行级 diff 出 added / removed / changed，逐列对照
- **DR-* 五类业务规则**：唯一性、不变式（金额=Σ明细）、守恒（转账总额不变）、
  状态机合法迁移、引用完整性——由自研受限表达式解析器求值，**不是 eval**
- **只读护栏**：DB 通道唯一入口 ReadOnlyGuard，只放行 SELECT，写 SQL 直接拒绝
- **data_gate 数据门禁**：数据断言失败、声明的校验没跑、通道故障——全部计入 FAIL

界面说成功不算成功，数据库说落对了才算。
